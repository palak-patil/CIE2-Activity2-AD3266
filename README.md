# Banknote Authentication Using Binary Logistic Regression

## Activity 2 – CIE 2

**Student Roll Number:** AD3266

### Project Description

This project uses Binary Logistic Regression to classify banknotes as genuine or forged based on four numerical features extracted from images of banknotes.

### Dataset

Banknote Authentication Dataset – UCI Machine Learning Repository

[https://archive.ics.uci.edu/dataset/267/banknote+authentication](https://archive.ics.uci.edu/dataset/267/banknote+authentication)

### Algorithm

Binary Logistic Regression

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score
- 5-Fold Cross-Validation
